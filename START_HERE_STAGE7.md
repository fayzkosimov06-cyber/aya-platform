# AYA — этап 7: накопительные баллы

## Обновление

Архив включает предыдущие этапы. Остановите сервер Ctrl+C, сохраните резервную копию проекта и базы. Замените код, сохранив собственные db.sqlite3, media, окружение и настройки.

В папке с manage.py:

```sh
python manage.py migrate
python manage.py check
python manage.py runserver
```

ВАЖНО: в этом обновлении есть новая миграция users/0033. Она создаёт таблицы баллов. Старые оценки не удаляются и не переводятся в баллы. После запуска обновите браузер Ctrl+F5.

## Первое начисление

1. Войдите руководителем, работником, президентом или суперпользователем.
2. Откройте «Работы и баллы» в меню пользователя или кнопку «Работы и начисления» в рейтинге. Адрес: /points/works/.
3. Откройте «Настроить виды помощи и баллы». Создайте ваши правила: название и положительное целое число баллов. Готовые суммы не навязаны.
4. Создайте работу: название, дата фактического выполнения, описание. Либо найдите ранее созданную работу по названию и откройте её.
5. Выберите вид вклада и одного или нескольких волонтёров. Добавьте комментарий и подтвердите начисление.
6. Для людей с другими обязанностями повторите начисление с другим видом вклада в той же работе.

Записи работ внутренние и не попадают в афишу. Модератор, обычный волонтёр и кандидат не могут начислять баллы.

## Мероприятия

Старая форма оценивания удалена из редактора отчёта; сервер также отклоняет старые команды сохранения/удаления оценок. В редакторе отчёта есть кнопка «Начислить баллы участникам». Она открывает общую работу, связанную с мероприятием. Для такого начисления доступны только зарегистрированные допущенные волонтёры. Повторный переход открывает ту же работу.

Дата работы подтверждается при создании. Для мероприятий начальное значение — дата окончания. Будущая дата не допускается. Регистрация, фотографии, отчёты и роли участников сохранены. Экспорт для справок пока не добавлен.

## Правила и исправления

- Каждый вид вклада начисляется одному волонтёру в одной работе один раз независимо от администратора. Другой вид вклада разрешён.
- Создание отдельной дублирующей работы не считается тем же основанием: перед созданием используйте поиск.
- Изменение стоимости вида помощи влияет только на новые начисления. Старые суммы сохраняются.
- Правило можно выключить, сохранив историю.
- Ошибочную сумму или комментарий исправляют через «Исправить / отменить / восстановить». Причина обязательна.
- Отмена исключает баллы из рейтинга; повторное начисление отменённой записи её не восстанавливает. Используйте исправление и снимите отметку отмены.
- В карточке работы есть журнал: ответственный, время, причина, значения до и после. Удаления начислений через интерфейс нет.

## Рейтинг и профиль

По умолчанию рейтинг за текущий учебный год: 1 сентября включительно — 1 сентября следующего года не включительно. Архивировать вручную ничего не нужно: суммы определяются датой работы.

Фильтры: учебный год (включая прошлые), текущий календарный месяц, текущая неделя с понедельника, всё время. Выбор года действует только в режиме учебного года. При одинаковой сумме место одинаковое.

Профиль показывает текущий учебный год, всё время и историю баллов с фильтром. Старые оценки 1–5 доступны в раскрываемом архиве и в новый рейтинг не входят. Гости и кандидаты не видят чужие начисления.
