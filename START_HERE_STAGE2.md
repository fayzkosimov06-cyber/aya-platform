# AYA — новая главная страница

Это полный архив кода, включающий исправления первого этапа и новую главную. Работа рассчитана на ваш локальный сервер. Сайт на PythonAnywhere не обновлялся.

## Как установить локально

1. Остановите runserver сочетанием Ctrl+C.
2. Скопируйте вашу текущую папку проекта в резервную папку, включая db.sqlite3 и media, если они есть.
3. Перенесите содержимое aya-platform-fixed в папку проекта с manage.py с заменой файлов. Не создавайте вложенную папку aya-platform-fixed. В архиве нет базы и пользовательских media; существующие файлы сохраняются.
4. Если вы изменяли aya_platform/settings.py самостоятельно, сохраните свои настройки базы, SECRET_KEY, DEBUG, ALLOWED_HOSTS и путей. В поставке сохранены настройки исходного архива и OPTIONS для SQLite из первого этапа.
5. В активированном виртуальном окружении, из папки manage.py:

```bash
python manage.py check
python manage.py migrate
python manage.py makemigrations --check --dry-run
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ и нажмите Ctrl+F5. При стандартном DEBUG=True и runserver collectstatic локально не требуется. Если у вас локально обслуживается собранная staticfiles, выполните также python manage.py collectstatic --noinput.

Новая миграция users/0030_homepage_content.py добавляет отдельную таблицу для фотографии и цитаты главной. Существующие пользователи, визиты и мероприятия не изменяются. Если первый этап уже установлен, его миграции повторно не выполнятся. Обычный makemigrations не нужен.

## Что изменилось

- Светлая главная по согласованному макету: синий и бирюзовый акценты, компактные секции, прямоугольная фотография.
- Новый присланный логотип и ASSOCIATION OF YOUTH ATSMU рядом с ним.
- Сохранены Главная, Мероприятия, Волонтёры, Администрация, О нас, вход и регистрация. Добавлена ссылка Контакты на нижний блок главной. Новости не добавлены.
- Уведомления со счётчиком, меню профиля, редактирование, выход и панели по ролям сохранены. На узких экранах меню раскрывается кнопкой.
- На фотографии нет статистики. Числа показаны один раз под верхним блоком.
- Используются активные числовые блоки редактора «О нас» с их собственными подписями. Если блоков нет, выводятся фактические количества волонтёров, одобренных мероприятий, направлений и школ. Примерные 1000+ из макета не перенесены.
- Все направления из базы выводятся сеткой без карусели и лимита. Нажатие открывает волонтёров выбранного направления.
- В афише — до трёх ближайших одобренных незавершённых мероприятий, время окончания которых не прошло. Для гостей учитывается публичность. Используются обложки событий и единая существующая AYA-заглушка.
- Шаги вступления соответствуют одобрению заявки и трём визитам.
- Контакты берутся из редактора «О нас»: Instagram/Facebook видны всем, Telegram — только при полном доступе. Адрес и email также показаны, если заполнены.
- Общая шапка и нижнее меню обновлены на всех страницах; внутренние формы, профили и возможности сохранены.

## Как поменять фотографию и добавить цитату

Войдите под суперадминистратором, руководителем, работником или президентом. Нажмите «Редактировать главную» над верхним блоком либо кнопку в панели администратора.

Адрес: http://127.0.0.1:8000/administration/home/

Можно загрузить верхнюю фотографию и заполнить цитату, автора, подпись и фото автора. Без текста и автора цитата не показывается. После сохранения откроется главная с изменениями. Удаление текста скрывает блок. По умолчанию используется существующая групповая фотография AYA с молодёжного фестиваля, а не иллюстративная фотография людей из макета.

Числа и контакты изменяются в существующем редакторе «О нас», ссылка на него есть под формой главной. Направления и события по-прежнему управляются через существующие разделы.
