# AYA — этап 5: рейтинг волонтёров

В архив включены предыдущие изменения главной страницы, фотографий, цитат и страницы «О нас».

## Обновление локального проекта

1. Остановите сервер Ctrl+C. Сохраните резервную копию текущей папки проекта.
2. Распакуйте архив. Перенесите обновлённый код в рабочую папку с заменой файлов. Сохраните собственные db.sqlite3, media, виртуальное окружение и локальные настройки. База и загруженные фотографии в архив не включены.
3. В терминале в папке с manage.py, с активным виртуальным окружением:

```sh
python manage.py migrate
python manage.py check
python manage.py runserver
```

4. Откройте http://127.0.0.1:8000/rating/ и обновите страницу Ctrl+F5.

Этот этап не добавляет новых миграций. Команда migrate применит миграции прошлых этапов, если они ещё не применены.

## Что изменилось

- Ссылка «Рейтинг» в меню, списке волонтёров и блоке оценок профиля.
- Карточки первых трёх мест, таблица с переходами в профили, своё место, страницы по 30 участников.
- Средний балл по оценкам одобренных завершённых мероприятий, на которые записан участник. Каждая оценка оценивающего имеет одинаковый вес. Рядом отдельно показаны количество оценок и количество оценённых мероприятий.
- При одинаковом среднем балле до сотых место одинаковое, например 1, 1, 3. Поэтому в карточках первых трёх мест может быть больше трёх человек.
- Профиль и рейтинг используют одинаковый набор оценок. Изменение или удаление оценки отражается при следующем открытии страницы.
- Гости и кандидаты видят пояснение о полном допуске, без оценок участников. Работники, руководители направлений, главный администратор и суперпользователи не участвуют в рейтинге. Волонтёры без оценок остаются в списке волонтёров.
- Минимального числа мероприятий для рейтинга пока нет: первая корректная оценка уже учитывается.

Существующие записи оценок не изменяются. Незавершённые, неодобренные мероприятия, оценки вне диапазона 1–5 и оценки людей, которых нет среди участников мероприятия, не входят в расчёт. Это также применяется к сводке в профиле.

## Проверка

Автоматически пройдено 39 тестов: рейтинг, доступ, заявки и мероприятия, главная, фотографии, цитаты и редактор «О нас». Проверка Django без ошибок, новых изменений моделей нет. Визуальная проверка в браузере не выполнялась.

Для ручной проверки войдите допущенным волонтёром, откройте рейтинг и профиль одного человека: средний балл должен совпадать. Если корректных оценок пока нет, появится пустое состояние. Затем проверьте гостевой вход: оценки должны быть скрыты.
