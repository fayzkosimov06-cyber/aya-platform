# AYA — фотографии и цитаты на главной

Полный архив включает предыдущие исправления и новые функции. Работайте локально; GitHub и PythonAnywhere пока обновлять не требуется.

## Установка

1. Остановите локальный сервер (Ctrl+C) и сделайте резервную копию проекта вместе с db.sqlite3 и media.
2. Скопируйте содержимое aya-platform-fixed поверх своей папки проекта с manage.py. Не заменяйте свою базу и media — их в архиве нет. Если вы меняли settings.py, сохраните свои настройки.
3. В виртуальном окружении, из папки manage.py:

```bash
python manage.py migrate
python manage.py check
python manage.py runserver
```

4. Откройте http://127.0.0.1:8000/ и нажмите Ctrl+F5. Версии CSS/JS обновлены для сброса кеша.

Новая миграция users/0031_home_slides_and_quotes добавляет таблицы фотографий и цитат. Уже загруженная в предыдущем редакторе фотография и заполненная цитата переносятся автоматически с сохранением ссылок на файлы. Старые поля оставлены для сохранности данных. Новые миграции вручную создавать не нужно.

## Где управлять

На главной нажмите «Редактировать главную», либо откройте:
http://127.0.0.1:8000/administration/home/

Доступ есть у суперадминистратора, руководителя, работников и президента. Модератор, волонтёр и кандидат редактировать главную не могут.

### Фотографии

В разделе «Фотографии» выберите сразу несколько файлов. До загрузки появятся миниатюры; затем нажмите «Загрузить выбранные».

- На главной фотографии сменяются каждые 7 секунд.
- Есть стрелки и кнопка «Пауза».
- Автосмена приостанавливается при наведении, фокусе клавиатуры и скрытой вкладке.
- При системной настройке уменьшения движения автосмена первоначально выключена; кнопка «Продолжить» позволяет включить её.
- В редакторе: ↑ ↓ меняют порядок; «Изменить» заменяет фото или описание; «Скрыть» временно выключает; «Удалить» убирает запись.
- Если активных фотографий нет, показана стандартная фотография команды из сайта. Если фото одно, кнопки смены не показываются.

### Цитаты

В разделе «Цитаты» выберите «По одной», «По две» или «По три» и нажмите «Применить». Если цитат больше, посетитель может листать группы стрелками. На телефоне несколько карточек располагаются в один столбец.

Автор может быть:

- Участник сайта: найдите человека по имени, роли или логину. Имя и фотография берутся из его профиля; при необходимости укажите подпись и отдельную фотографию. Нажатие на текст, фотографию или имя ведёт в профиль.
- Учёный или другой автор: введите имя, цитату, подпись, при желании фото и ссылку на источник. Без ссылки карточка не ведёт на другую страницу. Внешнему автору не требуется аккаунт.

Цитаты можно редактировать, скрывать, удалять и менять местами. Скрытые цитаты не передаются на публичную главную. Если цитат нет, всем виден блок «Здесь скоро появятся истории участников AYA»; редакторам дополнительно доступна кнопка добавления.

Функция удаления убирает запись с главной, но намеренно не удаляет физический файл из media: он может использоваться в другом месте или старой записи.

## Исправление шапки

Найдены и устранены старые правила, принудительно задававшие тёмный фон через !important. Шапка белая, меню тёмное, текущий раздел выделен синим. Все пункты меню и доступные по ролям действия сохранены.

Если у вас настроена отдельная раздача собранной staticfiles, дополнительно выполните:

```bash
python manage.py collectstatic --noinput
```

При обычном локальном runserver с DEBUG=True это не требуется.
