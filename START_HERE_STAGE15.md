# AYA — обновление 15: полномочия и журналы

Это полный исходный проект с предыдущими изменениями. База данных и загруженные фотографии в архив не входят.

## Установка поверх работающего сайта

1. Остановите локальный сервер. Сделайте копию проекта, db.sqlite3 и папки media. На PythonAnywhere выполняйте обновление в период без работы пользователей.
2. Распакуйте архив. Скопируйте содержимое aya-platform-fixed в папку проекта. Сохраните свои aya_platform/settings.py, .env, базу и media. Не заменяйте рабочие секреты и параметры хостинга настройками из архива.
3. Модуль users/management.py заменён папкой users/management/. Старый файл management.py можно удалить после резервной копии; новую папку обязательно скопируйте полностью.
4. В активированном виртуальном окружении, из папки с manage.py выполните:

```bash
python configure_controls.py
python manage.py migrate
python manage.py check
python manage.py runserver
```

configure_controls.py подключает обязательную серверную проверку прав к вашим существующим настройкам и сохраняет их резервную копию. Если подключение невозможно, скрипт сообщает об этом; не пропускайте этот шаг. Миграции 0040 и 0041 добавляют таблицы и переносят старый журнал.

На PythonAnywhere вместо runserver:

```bash
python manage.py collectstatic --noinput
```

Затем нажмите Reload на вкладке Web. В браузере обновите страницу с очисткой кеша (Ctrl+F5).

## Что добавлено

- Меню прав в меню аккаунта: поиск и массовый выбор людей, индивидуальные разрешения и запреты, область действия (свои, выбранные или все команды), подтверждение изменений. Создание новых команд требует доступа ко всем командам.
- Иерархия: суперадминистратор; начальник и работники; президент; модераторы и руководители направлений; учителя; волонтёры. Равные не меняют права друг друга. Дополнительное разрешение не повышает должностной уровень. После смены роли индивидуальные исключения сбрасываются.
- Общий журнал: изменения данных и состава команд, отказы, поиск, фильтры и значения до/после. Доступ отдельно настраивается. Просмотры и поисковые запросы находятся в отдельном закрытом меню суперадминистратора.
- Суперадминистратор скрыт в обычных списках, профилях и авторстве. Его действия сохраняются в закрытой истории с настоящим временем изменения. Старые записи о нём не доступны другим пользователям.
- Закрытое исправление баланса: добавить, вычесть или установить итог учебного года; добавить пропущенного участника к существующей работе и команде. Изменения итогов не создают фиктивных мероприятий. В профиле показываются только суммы за учебный год и всё время.
- Закрытое исправление дат: выберите тип записи и её ID из журнала. Можно исправить даты мероприятий, посещений, участия, доступа, периодов активности и работ. Реальное время исправления сохраняется отдельно.

## Хранение истории

Поиски и просмотры внутри AYA хранятся 90 дней. Очистка запускается периодически при запросах к сайту. Её также можно запускать по расписанию:

```bash
python manage.py purge_activity
```

Остальная история изменений сохраняется. Пароли, токены и другие секреты не записываются. Не собираются нажатия клавиш, поиски на чужих сайтах и команды терминала. Журнал фиксирует действия приложения, а не изменения базы сторонними инструментами. Старые действия, которые ранее не записывались, восстановить невозможно. Закрытость внутри AYA не удаляет технические журналы PythonAnywhere или сервера.

## Проверка

Прошли 110 автоматических тестов users/events, компиляция 68 шаблонов, проверка схемы миграций и применение миграций к отдельной копии базы. Внешний вид в реальном браузере в этой среде не проверен.

После установки проверьте под разными аккаунтами: выдачу и отзыв отдельного права, выбранные команды, массовое изменение, скрытость суперадминистратора и закрытое исправление баланса. Сравните страницы на телефоне и компьютере. Начальные права ролей выставляются автоматически; индивидуальные исключения настройте под свою команду.
