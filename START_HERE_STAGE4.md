# AYA — «О нас» и единый редактор

Полный архив включает этапы 1–3 и обновлённые страницу «О нас», редактор блоков, общие числа и контакты. Продолжаем локальную работу; сайт на PythonAnywhere не изменён.

## Установка

1. Остановите runserver (Ctrl+C). Скопируйте текущую папку проекта в резервную, включая db.sqlite3 и media.
2. Перенесите содержимое папки aya-platform-fixed из архива в папку проекта с manage.py с заменой файлов. База, пользовательские media и виртуальная среда в поставку не включены; сохраняйте свои файлы. Сохраните собственные настройки settings.py, если меняли их отдельно.
3. В активированном виртуальном окружении:

```bash
python manage.py migrate
python manage.py check
python manage.py runserver
```

Откройте http://127.0.0.1:8000/about/ и нажмите Ctrl+F5. При обычном локальном runserver collectstatic не нужен. Если у вас отдельно обслуживается staticfiles, выполните python manage.py collectstatic --noinput.

Новая миграция users/0032_about_stat_source добавляет выбор источника числа и переносит старые Instagram/Telegram из основных полей в список контактов, если там ещё нет записи такой платформы. Старые введённые числа остаются ручными, их значения и подписи не меняются. Старые поля контактов не удаляются, но публичные страницы теперь используют единый список контактов. Все ранее применённые миграции сохраняются.

## Как редактировать

Войдите под суперадминистратором, руководителем, работником или президентом. На странице «О нас» нажмите «Редактировать страницу», либо откройте:

http://127.0.0.1:8000/about/manage/

Адрес /administration/about/ ведёт в тот же редактор. Старый /administration/about/edit/ перенаправляет туда же и больше не сохраняет данные через отдельную старую форму.

### Основная информация

Заголовок и описание страницы, заголовок и текст миссии, видео, email и адрес. Описание и миссия сохраняют абзацы и переносят длинные слова. Ссылки YouTube/Vimeo распознаются для встроенного видео; прочие http/https ссылки доступны кнопкой «Смотреть видео».

### Ценности и деятельность

«Добавить блок» открывает компактную форму названия, текста и выбора иконки. Иконки представлены картинками и понятными подписями. Классы fa-solid вводить не нужно.

### AYA в цифрах

«Добавить число» позволяет выбрать:

- «Ввести вручную»: например, 125 или 100+, с собственной подписью;
- автоматический подсчёт: волонтёры, активные волонтёры, работники, руководители направлений, руководители школ, школы, направления, мероприятия.

Счётчики пользователей учитывают одобренные аккаунты и исключают суперадминистратора. Волонтёры исключают worker/head_admin/leader; президент остаётся волонтёром. Работники — worker/head_admin. Руководители школ считаются по уникальным людям, даже если один человек руководит несколькими школами. Мероприятия — одобренные.

Подпись и иконка задаются для каждой карточки. Числа, их подписи и порядок одинаковы на главной и в «О нас». При ручном режиме автоматически ничего не пересчитывается.

Если карточек ещё нет, обе страницы показывают фактические базовые счётчики волонтёров, мероприятий, направлений и школ. Чтобы скрыть весь блок цифр, скройте все существующие карточки: скрытые карточки не заменяются резервными числами. Удаление всех карточек возвращает базовые счётчики.

### Контакты и соцсети

Выберите платформу, введите ссылку/@имя/email/телефон и подпись. Иконка определяется автоматически. Instagram и Facebook доступны всем; Telegram только после полного допуска. Для других платформ можно включить ограничение доступа.

Обе публичные страницы используют один список и одинаковые правила. Скрытие контакта убирает его с обеих страниц; скрытый Telegram не попадает в HTML гостя или кандидата. Email и адрес из основной информации также видны на обеих страницах. Если добавить тот же email отдельной карточкой, удалите дублирующую запись самостоятельно.

### Пространство для новых идей

Дополнительные текстовые блоки с иконками. Пока записей нет, остаётся небольшой блок с предложением связаться с AYA.

### Управление записями

«Изменить» открывает только нужную форму. ↑ ↓ меняют порядок внутри раздела. «Скрыть» сохраняет запись, но убирает её с публичной страницы. «Удалить» удаляет запись после подтверждения. Новые записи показываются сразу.

Модераторы, обычные волонтёры, кандидаты и гости не могут менять эти данные.

```bash
python manage.py test users.test_regressions users.test_homepage users.test_home_media users.test_about_editor --noinput
```

Ожидаемый результат: Ran 31 tests, OK. Браузерная проверка оформления не проводилась — проверьте страницу локально. Пользователи, визиты, мероприятия, фотографии и цитаты этой миграцией не меняются. Рейтинг в этот этап не входит.
