# AYA — обновление 16: исправления управления

## Что исправлено

- Панель /administration/ открывается при наличии старых записей журнала без автора: вместо обращения к отсутствующему username выводится «Система».
- Новый редактор прав: поиск по имени/должности, выбор найденных людей, снятие выбора, группы разрешений, текущий доступ и итог изменений перед сохранением.
- Быстрые наборы добавляют только выбранные права. Другие разрешения не отключаются. Пропущенные в запросе поля сохраняют прежнее состояние.
- При ошибке изменения не применяются: появляется объяснение, выбранные значения сохраняются в форме. После успешного сохранения выводится сообщение.
- Для ограниченной области необходимо выбрать направление или школу. Нельзя сохранять пустой набор изменений.
- В управлении показываются ссылки на доступные действия. Выдача права на управление направлениями больше не требует дополнительного права на управление людьми для отображения кнопки создания.
- В профилях и фильтрах волонтёров/управления людьми используются единые списки: курс 1–6, пять согласованных факультетов, 18 городов Таджикистана. Подмена значений запроса не позволяет сохранить произвольный город или курс. Некорректный фильтр даёт пустой результат, а не ошибку сервера.
- Старые значения профиля не удаляются миграцией. Если значение не входит в справочник, при редактировании показывается подсказка и требуется выбрать корректный вариант.
- Обновлены размеры элементов, интервалы, адаптивная компоновка и состояния фокуса на страницах управления.

## Установка на действующий сайт

1. Сохраните резервную копию проекта, базы db.sqlite3 и папки media.
2. Распакуйте aya-platform-fixed. Скопируйте обновлённые файлы поверх проекта. Сохраните свои .env, media, db.sqlite3 и рабочий aya_platform/settings.py. В архиве дан settings.py.example — он не заменяет настройки сервера.
3. Если у вас остался старый файл users/management.py, уберите его после резервного копирования. Вместо него используется папка users/management/.
4. В консоли PythonAnywhere активируйте своё окружение и перейдите в проект (пути взяты с вашего снимка):

```bash
workon myenv
cd /home/AYA1/mysite
python configure_controls.py
python manage.py migrate
python manage.py check
python manage.py collectstatic --noinput
```

5. На странице Web нажмите Reload. Обновите сайт через Ctrl+F5.

Миграция 0042 добавляет справочники полей. Если обновление 15 ещё не применено, migrate последовательно применит и его миграции. Новые зависимости не добавлены.

Если используете GitHub: сначала перенесите изменения из архива в свой локальный репозиторий, проверьте git status, сделайте commit и push. На PythonAnywhere выполните git pull из папки проекта, затем команды обновления выше. Базу, фотографии, .env и рабочие настройки не отправляйте в публичный репозиторий.

Для первого локального запуска скопируйте aya_platform/settings.py.example в aya_platform/settings.py, установите requirements.txt, выполните migrate и runserver. Для работающего проекта этот шаг не нужен.

## Как менять права

1. Откройте «Права доступа» из центра управления или меню аккаунта.
2. Найдите человека либо выберите несколько найденных людей. Поиск не снимает уже сделанный выбор.
3. Откройте нужную группу. Под названием разрешения отображается текущий доступ; при массовом выборе — у скольких выбранных оно уже включено.
4. Выберите «Разрешить», «Запретить» или «По должности». «Не менять» сохраняет существующие настройки.
5. Если включаете права команд, укажите область: свои команды, конкретные команды или все команды. Область относится только к включаемым сейчас разрешениям команд.
6. Проверьте список внизу и нажмите «Сохранить права».

«По должности» возвращает правила текущей роли и назначений. Должности, имена и рамки этим действием не меняются. Настройки, случайно запрещённые старым быстрым набором, автоматически не восстанавливаются: невозможно отличить случайный запрет от намеренного. Проверьте таких пользователей в новом редакторе.

## Проверка

Пройдены 119 автоматических тестов, включая девять новых проверок ошибок и прав; скомпилированы 68 шаблонов. Проверены JavaScript и согласованность миграций. Проверка внешнего вида в реальном браузере и на вашем сервере ещё нужна: она не заменяется автоматическими тестами.

После установки проверьте панель администратора, сохранение одного права с последующей повторной загрузкой, массовой выбор, фильтры и редактирование профиля. Полный доступ к рабочему серверу не использовался; изменения находятся в архиве.
