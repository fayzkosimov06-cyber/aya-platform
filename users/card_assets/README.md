# Volunteer-card assets

`demo-portrait.png` is an AI-generated portrait of a fictional adult, created for
the design proof only. The staff-only sample labels it as demonstration data.
It is never used to populate an actual volunteer's card or profile.

Real cards use their own private photo snapshot and the selected edition's
logos, stamp and signature. The live sample contains no real seal or signature.

Fonts and their licence are in `fonts/`.
