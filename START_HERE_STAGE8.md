# AYA — этап 8: простой центр баллов

## Перед обновлением

Остановите сервер Ctrl+C и сохраните копию всей папки проекта, особенно db.sqlite3. В этом обновлении миграция 0035 УДАЛЯЕТ прежние оценки мероприятий по шкале 1–5 по вашему запросу. Восстановить их после миграции можно только из резервной копии. Новые накопительные баллы не удаляются.

Распакуйте архив и замените код. Сохраните свою базу db.sqlite3, папку media, окружение и локальные настройки. Затем в папке с manage.py:

```sh
python manage.py migrate
python manage.py check
python manage.py runserver
```

В браузере нажмите Ctrl+F5.

## Как начислять теперь

1. Откройте пункт «Баллы» в верхнем меню → «Начислить баллы».
2. Напишите за что, выберите дату и введите баллы каждому. Предварительно создавать правило или отдельную работу больше не требуется.
3. Введите имя или логин в поиске участников и отметьте человека. Продолжайте искать других: выбранные сохраняются и видны над списком. Нажатие на имя с крестиком снимает выбор.
4. Проверьте итог и нажмите «Начислить баллы».
5. После сохранения открывается работа с начислениями и сообщением об успехе. Если данные неверны, форма показывает ошибки и сохраняет введённое.

В профиле доступна кнопка «Отметить помощь»: этот волонтёр уже выбран.

Чтобы добавить людей в ту же работу, откройте Центр баллов → найдите работу → «Добавить участников». Или раскройте «Выбрать уже созданную работу» в форме начисления. Используется исходная дата работы.

Готовые правила остаются необязательными: при выборе правила число баллов подставляется автоматически. Его можно скорректировать перед сохранением. Для прямого начисления используется общий вид «Помощь — прямое начисление»; повторное начисление человеку этого же вида в той же работе блокируется. Исправляйте существующую запись через журнал работы.

Двойная отправка той же формы не создаёт ещё одну работу и не удваивает баллы. Повторные начисления показывают понятное сообщение. Для работы по мероприятию по-прежнему разрешены только его зарегистрированные участники.

## Дизайн

- Отдельный Центр баллов в верхнем меню и меню пользователя.
- Единая форма из двух карточек: работа и выбор участников; итог перед сохранением.
- Обновлённые карточки лидеров с фотографиями, светлая сине-голубая палитра.
- В профиле карточки баллов за учебный год и всё время, история с выделенными начислениями.
- Старые оценки и их архив удалены из профиля.
- Добавлен отступ под фиксированную шапку, чтобы заголовок не перекрывался.
