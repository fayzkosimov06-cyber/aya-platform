# Проверка интерактивного обучения AYA

Проверено 15 сентября 2026 года. Среда: Windows, Python 3.13.7, Django 5.2.7, SQLite. Исходник — предоставленный ZIP, Git HEAD `979fb2d5305baa62a60b595919b43c3c37a1e32e`.

## Автоматические проверки

- `python manage.py test --noinput`: **131 тест, OK** (119 существующих и 12 новых).
- `python manage.py check`: ошибок нет.
- `python manage.py makemigrations --check --dry-run`: изменений моделей без миграций нет.
- `node --check static/js/training.js`: синтаксических ошибок нет.
- Миграции применены на отдельной пустой SQLite-базе.
- Отдельно выполнен переход с `users.0042` на `users.0043` с существующим одобренным пользователем: все его поля сохранены, принудительное обучение не создано.

Новые тесты проверяют: кандидатов и отзыв доступа; ручную выдачу и третье посещение; повторную выдачу; начало, паузу, продолжение, завершение и повтор; восстановление после нового входа; невозможность менять чужой прогресс; неверные JSON, темы, версии и методы; конфликт двух вкладок; CSRF и авторизацию; пустые каталоги; наличие целей подсветки в реально используемых шаблонах; отсутствие записи на мероприятие и чтения уведомлений при просмотре учебных страниц.

## Проверки в браузере

На локальной копии с отдельными тестовыми данными проверены:

- приветствие после выдачи доступа и первые шаги основного знакомства;
- открытие и восстановление мобильного меню, подсветка аккаунта;
- Tab, выход по Escape, снятие затемнения и блокировки страницы;
- сохранённая пауза в помощи и восстановление текущего шага после перезагрузки;
- переход из помощи на страницу мероприятия;
- пояснение при отсутствии предстоящих мероприятий;
- переход к появившемуся тестовому событию, подсветка настоящей кнопки «Присоединиться»;
- нажатие по координатам подсвеченной кнопки во время обучения: запись не произошла;
- завершение темы мероприятий и статус «Завершено» в помощи;
- все четыре шага профиля, включая приватность и кнопку сохранения, без отправки формы;
- визуальная проверка при размерах 1256×912, 390×844 и 320×568.

При проверке исправлено перекрытие цели раскрытым мобильным меню. Добавлено место для прокрутки у конца страницы, чтобы подсказка не закрывала кнопку сохранения на маленьком экране. Временные стили восстанавливаются при выходе.

## Границы проверки

Проверка на production не выполнялась. Реальные пользователи, база и медиа из архива не изменялись. Версия Python 3.10 на PythonAnywhere отдельно не запускалась. Реальные iOS/Safari и Android не проверялись: мобильная проверка выполнена изменением размера браузера. Полный ручной проход всех шагов школ, направлений и рейтинга не выполнен; их маршруты и серверный рендеринг проверены автоматическими тестами. После основных браузерных сценариев инструмент управления браузером начал возвращать тайм-ауты, поэтому дальнейший визуальный проход был ограничен. Сбой сети во время сохранения не воспроизводился вручную; обработчики ошибок и возможность немедленного выхода предусмотрены в коде.

Для интерактивного обучения требуется JavaScript и браузер с поддержкой HTML dialog. Новых внешних библиотек или CDN для обучения нет; существующие подключения оформления сайта сохранены.
