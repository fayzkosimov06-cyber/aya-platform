# AYA — этап 6: профиль и история оценок

Архив включает предыдущие этапы. Остановите локальный сервер (Ctrl+C) и сделайте резервную копию проекта. Перенесите код из архива с заменой файлов, сохранив свои db.sqlite3, media, виртуальное окружение и локальные настройки.

В папке с manage.py выполните:

```sh
python manage.py migrate
python manage.py check
python manage.py runserver
```

Откройте профиль и обновите Ctrl+F5. Новых миграций на этом этапе нет.

## Изменения

- Светлый верхний блок профиля, голубые акценты, более компактная фотография, оформление карточек и форм периодов деятельности.
- Полная история оценок по 10 записей на страницу: мероприятие, оценивающий, дата обновления, роль на мероприятии, критерии, балл и комментарий.
- Фильтр по мероприятию с сохранением при переходе между страницами. Сводный средний балл остаётся общим независимо от фильтра.
- История использует те же оценки, что рейтинг: одобренные завершённые мероприятия, регистрация участника и корректный балл 1–5.
- Сохранены существующие периоды деятельности, перерывы, создание, изменение, удаление с подтверждением и журнал действий. Исправлен формат дат при открытии формы редактирования. Пустая дата окончания означает текущий период.
- Права сохранены: периоды меняют руководители, работники, главный администратор и суперпользователь. Модератор и президент не могут их менять. Чужая история оценок скрыта от гостей и кандидатов; собственные данные доступны владельцу.

## Ручная проверка

1. Откройте профиль с оценками, проверьте комментарии и критерии.
2. Выберите одно мероприятие: история фильтруется, общий балл не меняется. Нажмите «Сбросить».
3. При более чем 10 оценках проверьте следующую страницу.
4. От имени работника откройте «Периоды деятельности → Управлять»: добавьте завершённый период и следующий с перерывом, проверьте редактирование дат.
5. Откройте чужой профиль без входа: история оценок должна быть скрыта.
6. Проверьте профиль на компьютере и телефоне.
